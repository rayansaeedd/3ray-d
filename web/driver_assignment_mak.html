Driver Task Assignment — Makkah Station

Set the schedule dates, drop the Task Program and Roster, set your conditions, and generate -- assigns drivers by shift rotation, reserve/trip ratio and rest-time rules, and writes the results into both files.

1. Schedule dates

Each tab in the Task Program file is treated as one consecutive day starting from the first date, in the order the tabs appear in the workbook -- the last date is just used to confirm the range before you drop files.

3. Conditions

These have to be set before you can generate. They're remembered on this device -- come back and Edit any of them any time.

4. Result

"Unassigned tasks" = the rest-time rule (the only hard limit -- never bent) ruled out every available driver that day, or there were simply more tasks than available drivers. Shift-lock is a soft preference: a driver outside their locked shift still gets picked over leaving a task unfilled. "Unassigned drivers" = every task that day was already filled and this driver was left over -- in the downloaded roster file, that driver's day cell is recolored magenta so it stands out from an ordinary blank/available cell.

5. Monthly summary -- shift & trip/reserve load per driver

Keep this as a reference for next month -- if someone got more trips this run, lean their reserve/trip mix the other way next time.

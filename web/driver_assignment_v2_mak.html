4. Conditions

These have to be set before you can start. They're remembered on this device -- come back and Edit any of them any time.

5. Day-by-day generation

Loading builds this session from the files/dates/conditions above. Pick a day, Generate it, review the counts below, then Save it as a checkpoint once you're happy -- only saved days feed the next day's Generate. Saving is never final: you can Edit a saved day (which un-saves it) to change it and save again as many times as you like. Only Grant, at the bottom of this card, finalizes anything.
"Unassigned tasks" = the rest-time rule (the only hard limit) ruled out every driver in this task's own locked shift and the shift(s) immediately next to it, or there were simply more tasks than available drivers. "Unassigned drivers" is left genuinely blank on purpose -- no manufactured reserve duty -- for you to fix by hand (that editing comes in a later step of this build).
The real finish line: once you've saved as many days as you want for this month, Grant confirms exactly how many days are currently saved (out of the whole session), finalizes them as the month's schedule, saves that as memory for next month, and downloads a backup copy. Grant this once you're done reviewing the whole month -- not after every single day.

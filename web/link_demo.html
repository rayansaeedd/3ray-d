Demo: write directly into a local Excel file (no download)

This is a standalone experiment, completely separate from the real driver-assignment tool. Nothing here touches the engine, and it never will unless this works and you approve it.

Test this on a spare copy of a spreadsheet first, not a real important file, until you're comfortable with how it behaves.

1. Browser support check

2. Link a local .xlsx file

Pick any real .xlsx file on your computer (ideally a spare test copy). This does NOT copy it anywhere -- the tool keeps a direct reference to that exact file.

3. Write a value directly into that same file

Pick a cell and a value, then write it straight into the file on disk -- no "Save As", no download, no second copy. If the file is open in Excel at the time, close and reopen it afterward to see the change (Excel doesn't auto-refresh when another program edits a file it has open).

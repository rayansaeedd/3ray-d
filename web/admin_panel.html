Green = task assigned by the engine · blue = RESERVE · black = original off-duty code (F/V/O/etc.) or fixed 830/7T assignment · purple = a Training code you've placed · red = a trip that lost its driver to training and still needs one. Every box is editable: type a training code (defined in the Training tab) over a driver's day(s) to send them to a course -- click Save roster changes when done.
Origin is one station for the whole schedule (set below), since it's this supervisor's own base. Trip tasks have their own outbound leg (box #, start, end) and return leg (box #, start, end) -- each editable independently. Reserve tasks only use the "Out. Start"/"Out. End" columns as a plain Start/End. Long-press the ⋮⋮ handle on the left of a row and drag to reorder. Changing anything here takes effect the next time you click "Generate month". The Day Schedule itself is read-only -- all editing happens here.
Real roster data only covers October 2026 right now, so dates outside Oct 1–31, 2026 aren't available -- ask if you want another month added.
Define a course here (its own Code, date range, time window, name, and seat capacity), then search for drivers by name under Assigned Drivers and pick everyone going -- picking/removing a driver only edits that list. Click this row's own Save button when you're done to write the code into the roster for everyone on the list, across the whole date range (and clear anyone you removed) -- nothing touches the roster until you click it. (Typing the code into a Full Roster cell yourself still works too, for a single day at a time, and keeps this list in sync.) The engine keeps a trained driver off the task schedule for those days. If a driver already had a real trip that day, the engine tries to backfill it from another driver on Reserve that same day/shift; if nobody's free, that box turns red so you know to reassign it by hand.
